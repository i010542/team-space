大家的修改版本

每个人可以单独保存一份修改。GitHub 把这些版本叫作“分支”，它们不一定已经被团队采用。

接下来怎么做

  1. 1

    打开版本列表，找到你想看的成员或任务名称。

  2. 2

    点击名称，查看这一份版本里的文件；列表也可能包含已经结束的任务。

  3. 3

    想看哪些修改正在等待团队处理，请到“待审核的修改”。

下一步会打开 GitHub。需要使用有 FVA 项目权限的账号；如果看不到页面，请确认账号或联系项目负责人。

去 GitHub 查看修改版本 ↗
查看团队文件大家的修改版本待审核的修改提问题或建议

继续修改自己的 FVA

回到客户端选择文件、发给团队审核，或获取团队新版。
