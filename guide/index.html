FVA · 团队协作客户端

开始参与 FVA

完成下面的三步，在本地客户端查看使用帮助、选择改动并提交审核。

在本地客户端打开 FVA首次使用：下载 Windows 客户端

第一次使用

  1. 01

    下载并安装

    运行 Windows 安装程序。安装后可以直接打开客户端，也可以从这里打开。

  2. 02

    选好你的 FVA 文件夹

    登录 GitHub 后，选择你平时正在使用的 FVA 文件夹。客户端会记住它的位置。

  3. 03

    照常修改，发给团队看

    继续用 WorkBuddy 或 Codex 修改。保存后，在客户端选好文件，发给团队审核。

打开客户端后可以做什么

  • 项目和资料

    查看 FVA 项目，按关键词或分类查找资料。

  • 改动和审核

    绑定正在使用的 FVA，查看改动、选择文件并提交审核。

  • 更新和恢复

    检查团队更新、处理冲突、备份并更新本机文件。
