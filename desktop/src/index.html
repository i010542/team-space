            常见问题
            
            
            为什么进不了项目或发不了改动？
            请确认浏览器和客户端都在用团队已开通权限的 GitHub 账号。仍有问题时，请联系项目负责人。
            
            
            为什么这一批改动发不出去？
            一次发送必须包含这次的全部改动。有文件不能发送时，请看文件旁的原因，处理后再刷新。一次最多发送 100 个文件。
            
            
            刚选好 SKILL.md，为什么已经有改动？
            客户端会拿文件夹里的文件和团队当时的版本对照。之前改过的文件也会列出。从来没有安装过的文件不会算作你删除了它。
            
            
            选了「保留我的版本」，怎样继续发送？
            先在原文件中补上你需要的团队改动，再检查更新。如仍需选择，选「保留我的版本」并确认更新。
            
            
            怎么知道团队采用了我的改动？
            审核进度显示「已采用」时，改动已经进入团队正式版本。刚发出时，请等团队审核。
