        第一次参与

        完成一次共创

        1. 01
          用 GitHub 登录

          在工作台点击「GitHub 登录」，在浏览器使用团队授权的账号完成验证。

        2. 02
          绑定现有的 FVA

          点击「选择正在使用的 FVA 文件夹」，选择直接包含 SKILL.md 的目录。绑定后仍在原目录用 WorkBuddy 或 Codex 修改和保存。

        3. 03
          挑选文件并提交审核

          回到工作台，刷新改动，查看每个文件的摘要。只勾选这次要提交的文件，写一句修改说明，再点击「提交审核」。

        4. 04
          查看审核和更新 FVA

          点击「查看结果」查询审核进度。检查团队更新后，先看文件预览并处理冲突，再确认更新。需要时可以恢复到更新前的版本。

        常见问题

        为什么提示没有项目权限？

        先确认浏览器和客户端使用的是团队授权的 GitHub 账号；如仍无法访问，请联系项目负责人开通项目访问与提交权限。

        为什么有些文件不能勾选？

        客户端仅允许提交项目支持的文件。请按文件旁的提示调整，不要把密钥、账号配置或个人资料放进项目。

        首次绑定后，改动是怎么判断的？

        工作台以绑定时的团队版本为对照，显示这份 FVA 中已有的差异。未安装的团队文件会保持缺省，不作为你的删除改动。

        更新时保留了本机版本，怎样继续提交？

        首次保留本机版本会暂缓提交该文件。请先在原目录合并需要的团队内容，再检查团队更新。如仍有冲突，选择保留本机版本并确认更新。

        怎么知道修改进入了正式版本？

        审核状态显示「已合并」时，修改才进入正式版本。仅提交审核或审核关闭，不代表修改已经合入。
