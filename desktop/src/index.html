        共创入门

        使用帮助

        从选择 FVA 文件夹开始，一步步把改动发给团队。

        第一次参与

        完成一次共创

        1. 01
          用团队账号登录

          GitHub 是团队保存文件和审核改动的地方。在工作台点「登录 GitHub」，按浏览器提示完成登录。

        2. 02
          选择现在用的 FVA 文件夹

          选择打开后就能看到 SKILL.md 的文件夹。客户端会记住它。以后仍在原处用 WorkBuddy 或 Codex 改文件。

        3. 03
          选文件，发给团队审核

          保存后回到工作台，点「刷新改动」。勾选这次要发的文件，写一句说明，再点「发给团队审核」。

        4. 04
          看审核进度，按需更新

          点「刷新审核进度」看结果。要更新自己的 FVA，先看哪些文件会变，再确认。需要时可以恢复更新前的文件。

        常见问题

        为什么进不了项目或发不了改动？

        请确认浏览器和客户端都在用团队已开通权限的 GitHub 账号。仍有问题时，请联系项目负责人。

        为什么有些文件不能勾选？

        请看文件旁的原因。项目只接收支持的文件，密码、密钥和个人资料请留在本机。

        刚选好文件夹，为什么已经有改动？

        客户端会拿你的文件和团队当时的版本对照。之前改过的文件也会列出。从来没有安装过的文件不会算作你删除了它。

        选了「保留我的版本」，怎样继续发送？

        先在原文件中补上你需要的团队改动，再检查更新。如仍需选择，选「保留我的版本」并确认更新。

        怎么知道团队采用了我的改动？

        审核进度显示「已采用」时，改动已经进入团队正式版本。刚发出时，请等团队审核。
