# 团队共创空间 0.3.0 · 更新正在使用的 FVA

绑定实际使用的 FVA 文件夹，继续用熟悉的工具修改 Skill，再回到客户端提交审核或应用团队更新。

- 绑定不会搬动文件或初始化 Git；个人分支和提交由后台副本管理。
- 检查团队更新后，可在客户端比较差异、处理冲突，再选择「更新我的 FVA」。
- 更新先备份；不冲突的文本修改合并，同一处修改必须选择保留本机或使用团队内容。
- 未知旧版安装来源时，保守确认差异，不把本地内容直接覆盖。
- 支持恢复更新前的文件；恢复前检查是否有更新后的新修改，避免覆盖。
- 待发送提交和进行中的审核需要先处理，再应用团队更新。应用后使用新后台任务，旧任务保留。

Windows x64 预览版，仅接入 FVA，支持单个不超过 1 MB 的 UTF-8 文本文件。升级后选择直接包含 SKILL.md 的实际目录；绑定过的目录继续保留。更新和恢复期间请暂停编辑。
