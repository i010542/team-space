# 团队共创空间 0.4.0 · 本地统一工作台

项目、资料目录、使用帮助和协作操作统一放在本地客户端。[下载网页](https://i010542.github.io/team-space/) 只提供安装、升级和打开入口。平时直接使用桌面上的团队共创空间。

- 客户端集中项目列表、资料搜索与分类、使用帮助、修改提交和团队更新。
- GitHub 登录、仓库原文与人工审核从客户端打开浏览器。
- 网页简化为下载和打开客户端，旧网页地址保留兼容入口。
- 客户端未运行和已经运行两种情况均处理网页请求；操作忙碌或有草稿时保留当前内容，等待继续。
- 网页请求仅用于定位页面，不会自动登录、绑定目录、提交审核或应用更新。
- 保留绑定原 FVA、选择改动提交审核、比较并备份更新、离线中断恢复等已有能力。

Windows x64 预览版，仅接入 FVA，支持单个不超过 1 MB 的 UTF-8 文本文件。升级后选择直接包含 SKILL.md 的实际目录；绑定过的目录继续保留。更新和恢复期间请暂停编辑。

协议解析、冷启动和已运行窗口的导航交接使用隔离测试验证，网页与界面使用模拟客户端验证。未修改真实 FVA。安装后浏览器唤起客户端、真实 PR 审核闭环、新成员首次授权和其他电脑安装仍需试用验证。

安装包未做商业代码签名。校验值见 SHA256SUMS.txt。源码及第三方说明位于仓库 desktop/。
