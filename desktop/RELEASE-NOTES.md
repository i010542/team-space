# 团队共创空间 0.1.0 · Windows 预览版

无需安装 GitHub Desktop 或输入命令：连接 GitHub，开始参与 FVA，打开文件夹交给熟悉的工具修改，再选择文件提交审核。

包含：
- 自动准备独立个人分支和工作文件夹。
- 只读改动预览、文件选择、提交审核、审核状态查询。
- 更新工作文件、失败重试，以及保留旧文件重新开始的恢复入口。
- 内置 Git 和 GitHub CLI；文档在浏览器只读查看。

范围：Windows x64；当前接入 FVA；单个不超过 1 MB 的 UTF-8 文本文件。正式版本仍由维护者合并，不自动运行 Skill。

验证：本机真实 GitHub 登录状态、FVA 权限、下载及本地分支准备已通过；提交和恢复流程使用隔离 Git 仓库与模拟 GitHub 响应验证。尚未完成真实 FVA PR 的完整审核闭环、新成员首次授权和其他电脑安装验证。

此安装包未做商业代码签名。若组织策略阻止安装，请交由管理员检查，不要关闭系统安全保护。校验值见 SHA256SUMS.txt。

客户端源码见仓库 desktop/ 目录；第三方许可和对应源码链接见 desktop/THIRD-PARTY-NOTICES.md。
